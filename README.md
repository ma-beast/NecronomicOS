# Naive BASIC

Naive BASIC is a small BASIC programming environment for Android, inspired by the simplicity and spirit of classic 8-bit computers.

It is not an emulator. Naive BASIC is a native Android application with its own BASIC interpreter, designed around a simple, compact language and a Spectrum-like programming experience.

## Features

- BASIC interpreter for Android
- Syntax inspired by classic G/Q-BASIC & ZX Spectrum-128 BASIC
- Runs on low-end and older Android devices
- Simple built-in program editor
- `SAVE` / `LOAD` support for BASIC programs
- Text and graphical output
- Touch-screen input
- 256-color `INK` / `PAPER` palette
- `SCREEN`, `PLOT`, `LINE`, `CIRCLE`, `OVAL` and `TRIANGLE` graphics
- `PLAY` command for simple music and sound
- `KEY`, `SCREENX`, `SCREENY`, `TOUCHX`, `TOUCHY` and other hardware-oriented functions
- No external BASIC runtime required

## Philosophy

Naive BASIC is intentionally small and straightforward.

The project is about bringing back the feeling of writing programs on an old home computer: type some BASIC, press RUN, and immediately see something happen.

It is also an experiment in how much can be built with a minimal BASIC language — from simple text programs to graphical demos, games and music tools.

## Compatibility

Naive BASIC targets Android devices starting from Android 2.3 and was designed with older ARM hardware in mind.

Newer Android versions are supported as well.

## Examples

Programs created with Naive BASIC include:

- graphical demos
- small games
- interactive applications
- procedural graphics
- music and sound experiments
- a touch-screen music editor

## Status

Naive BASIC is an ongoing hobby project.

The interpreter and language are developed experimentally, with new commands and improvements added when they prove useful in real programs.
